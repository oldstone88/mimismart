# Как работает скрипт:
1) Закидываем 95.sh *\(при необходимости смените номер*\) в /home/sh2/exe/
2) Выдать права на исполнение
3) Закинуть скрипт rebootFromRelay.txt в /home/sh2/scripts/
4) Завести скрипт указав IP реле и какие каналы *\(Начинаются с 0\)* реле перезагружать
P. S. Время снятия питания - 10 секунд.
